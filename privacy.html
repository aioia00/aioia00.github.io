Privacy Policy

Last updated: October 19, 2026

AIO YouTube Uploader ("the App") is a personal tool used only by its developer to upload the developer's own videos to the developer's own YouTube channel. This policy explains how the App handles data.

YouTube API Services

The App uses YouTube API Services. By using the App, you agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

Data the App accesses

  • The App requests only the OAuth scope https://www.googleapis.com/auth/youtube.upload, which allows it to upload videos to the signed-in user's channel.
  • It does not read, collect or analyze any other YouTube or Google account data.

How data is used and stored

  • Video files, titles, descriptions, tags and schedule settings come from files on the user's own PC and are sent only to YouTube to create the upload.
  • The OAuth access and refresh tokens are stored only in a local file on the user's PC. They are never sent to the developer or any third party.
  • After each upload, the App writes the uploaded video's ID, title and upload time to a local log file on the user's PC.
  • The App has no server. No data is collected by the developer.

Sharing

The App does not sell, share or disclose any user data to third parties. Data is sent only to Google/YouTube as needed to upload the video.

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

  • You can revoke the App's access at any time from Google Account security settings (Third-party apps & services).
  • Deleting the local token file and log file on the PC removes all data stored by the App.
