AIO YouTube Uploader

A personal tool that uploads my own videos to my own YouTube channel.

What it does

AIO YouTube Uploader is a small script that runs on the developer's own Windows PC. When a finished video file is placed in a local folder, the script uploads it to the developer's own YouTube channel through the YouTube Data API (videos.insert), using the title, description, tags, privacy setting and publish schedule written in a small text file next to the video.

  • Single user: only the channel owner uses it.
  • It only uploads videos. It does not read, collect, analyze or display any YouTube data.
  • OAuth tokens are stored only on the owner's PC.

概要（日本語）

AIO YouTube Uploader は、開発者本人のパソコンで動く個人用のツールです。ローカルのフォルダに置いた自作の動画を、YouTube Data API を使って本人の YouTube チャンネルにアップロードします。利用者は本人だけで、動画のアップロード以外に YouTube のデータを読み取ったり保存したりはしません。
